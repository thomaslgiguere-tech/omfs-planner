# Glossary: Blender for Meshmixer users

Blender term → what it actually does → closest Meshmixer equivalent. Grows with every feature.

| Blender term | What it does | Meshmixer equivalent |
|---|---|---|
| **Object** | A container placed in the scene: name, position/rotation/scale, colour, and a link to its data (e.g. a mesh). | An object in the Object Browser. |
| **Mesh (data-block)** | The actual vertices, edges and faces. Separate from the object, so two objects can share one mesh. We name both after the file. | None: in Meshmixer an object *is* its mesh. |
| **Data-block** | Any reusable thing stored in a .blend file (objects, meshes, scenes, workspaces...). | None. |
| **Scene** | Everything in one planning case: objects, units, settings. | The whole Meshmixer session. |
| **Blender unit (BU)** | Blender's internal length unit. We set **1 BU = 1 mm**. Mesh coordinates are stored as raw numbers; the unit only changes how they are displayed. | Preferences > Units/Scale (mm). |
| **Unit scale / length unit** | Scene > Units. `scale_length = 0.001` + `MILLIMETERS` makes Blender show 1 BU as "1 mm". The vertex coordinates are not changed. | Same as above. |
| **Transform (location / rotation / scale)** | Where the object sits. Changing it moves the whole object **without** changing the vertex coordinates stored in the mesh. | Edit > Transform. |
| **Origin** | The object's pivot point. Imported meshes keep their origin at the file's 0,0,0, so all meshes from one case stay registered. | Transform pivot. |
| **Transform locks** | Per-axis padlocks on location/rotation/scale: the object can't be moved by hand. | None. |
| **Selectable (`hide_select`)** | When off, clicks go through the object in the viewport and outliner. It stays visible, and the Measure tool can still snap to it. Together with transform locks this is our **Lock**. | None (Meshmixer can only hide objects). |
| **Import axes (forward / up)** | Importers can rotate a file while reading it. We force forward = Y, up = Z, scale = 1, which means "keep the file's coordinates as-is". Blender's OBJ importer rotates by default! | Meshmixer imports raw coordinates. |
| **Empty** | An object with no mesh: just a position and three axes. We use one as the clinical reference frame, so the anatomy never has to be moved or rotated. | None. |
| **Rigid transform** | Rotation + translation only (no scale), stored in the object's transform. The vertices, so the shape, are untouched. Used to register the intra-oral scan. | The result of Align: the object moves, its shape doesn't. |
| **Point-pair alignment (Kabsch)** | Least-squares rotation + translation that best maps ≥3 clicked points on one mesh onto their partners on another. Coarse: gets within ~1 mm. | Align > manual point pairs. |
| **ICP (iterative closest point)** | Repeats: find the closest surface point for each scan crown point, move the scan to reduce those distances (point-to-plane), until it stops moving. Rigid only here. | Align > surface align. |
| **Vertex group** | A named set of vertices (with a 0-1 weight each) stored on a mesh. Our "Crowns" group says which scan vertices ICP uses. Doesn't move any vertex. | A saved selection. |
| **Weight Paint mode** | Paint vertex-group weights with a brush: red = 1 (used), blue = 0 (ignored). Used to correct the crown selection. | Select brush (but saved, and with weights). |
| **Color attribute** | A colour per vertex stored on the mesh. We write the registration distance map into one; Viewport Shading > Color > Attribute shows it. | Vertex colours / Analysis > Deviation colours. |
| **Raycast** | Shoots an invisible ray from the mouse into the scene and returns the first surface point it hits. How landmarks are snapped onto bone. Reads the mesh, never changes it. | What happens when you click a point on a surface (e.g. Drop Pivot). |
| **Modal operator** | A command that stays active and listens to the mouse/keyboard until it finishes (e.g. "click to place a landmark", Esc to cancel). Orbit and zoom still work meanwhile. | An active tool waiting for clicks (e.g. Measure). |
| **Collection** | A folder of objects in the Outliner. Landmarks go in the "Landmarks" collection. | None (Meshmixer has no folders). |
| **Landmark** *(OMFS Planner)* | A named Empty placed on a surface by raycast (Porion R, Nasion, Pogonion...). Locked after placing; place it again to move it. | None (closest: Drop Pivot, but unnamed and not saved). |
| **Parent / child** | A child object follows its parent's transform. The three reference planes are children of the frame Empty, so updating the frame moves them together. | None (closest: grouping objects). |
| **Reference frame** *(OMFS Planner)* | Empty built from porions, orbitales, nasion and basion: Frankfort horizontal, midsagittal and coronal planes, origin = nasion projected on FH. Movements are measured in its axes (left +, anterior +, up +). The anatomy is never moved. | None (Meshmixer only has the world axes). |
| **Boolean modifier** | Combines two closed meshes: Intersect (keep the overlap), Difference (subtract), Union. We cut the bone with a prism under the osteotomy plane: Intersect = segment, Difference = proximal part. New objects are made; the source mesh is untouched. | Edit > Boolean. |
| **Boolean solver (Exact / Manifold / Float)** | Exact: robust, works on meshes with small holes (our CBCT bone), ~1 s on a mandible. Manifold: much faster but refuses any mesh that isn't watertight. Float: older, fragile. | None (Meshmixer picks for you). |
| **Closest point on mesh** | Finds the nearest surface point to a given point. Used to snap the yellow stars onto the buccal bone. Reads the mesh only. | None. |
| **Osteotomy plane** *(OMFS Planner)* | Yellow plane placed below the midpoint of the mental foramina, with height, profile angle, frontal angle and posterior extents measured in the reference frame. Apply Cut splits the bone along it. | Plane Cut, but parametric and re-doable. |
| **Gizmo** | An interactive handle drawn in the 3D view (arrow, ring...) bound to a property: dragging it changes the value, typing the value moves it. The osteotomy has a height arrow, profile and frontal rings, and posterior-extent arrows. | Transform tool arrows and rings. |
| **Pivot point** | The point a rotation turns about: what stays put while the rest swings. Blender's own pivot (header menu: Median Point, 3D Cursor, Individual Origins...) only matters for R; our segment movement has its own pivot (pogonion, menton or segment centre), and changing it never moves the segment. | Transform tool: the pivot is the widget's centre, moved with the pivot handle. |
| **Euler angles (pitch / roll / yaw)** | A rotation written as three turns about fixed axes, applied in a fixed order (X, then Y, then Z). Pitch = about left-right, roll = about front-back, yaw = about vertical. The mesh data is untouched: only the object's transform changes. | Transform tool rotation fields. |
| **Segment movement** *(OMFS Planner)* | Six numbers on each segment (advance, up, left in mm; pitch, roll, yaw) about a pivot, on the osteotomy plane's axes (advance slides along the cut) or the reference frame's. The segment's transform is computed from them and its pre-op pose: arrows / rings in the view and typed values write the same numbers. The segment's transform is locked so G / R can't bypass them. | Transform tool with typed values, but on clinical axes. |
| **Sculpt Mode** | Mode where brushes act on the surface. Zones (Face Set) and Mask are painted on a painting copy of the bone; brushes (section 7) on free parts only (guide, cap). | Sculpt (but here only for selecting zones). |
| **Mask (sculpt)** | A 0-1 value painted per vertex (dark grey = masked). Can grow, shrink, smooth, invert. | Select brush (the selection). |
| **Face Set** | A group number stored on each face (attribute `.sculpt_face_set`), shown as a colour in Sculpt Mode. As many zones as needed at once, with sharp borders along the triangle edges; saved with the mesh. Painted with the Face Set Paint brush (each stroke = a new zone, Ctrl = continue the zone under the mouse) or the Lasso Face Set tool. Grow / Shrink by one ring of faces (Ctrl+W / Ctrl+Alt+W). | Facegroups (Select brush + Create Facegroup). |
| **Hide / isolate a face set** | H hides the face set under the mouse, Shift+H shows only it, Alt+H shows everything. Faces are only hidden (attribute `.hide_poly`), never deleted. | Hide (Facegroups). |
| **Face set → mask** *(OMFS Planner)* | Masks exactly the vertices of the chosen zone, to smooth its border with the mask filters before extracting. | None. |
| **Mask as protection** | In Sculpt Mode every brush and filter leaves masked vertices (dark grey) exactly where they are. "Polir l'extérieur" masks the guide's intrados (vertices within 1 mm of the bone) so the outside can be sculpted freely without touching the fit. | Freeze. |
| **Mesh Filter (Smooth)** | Sculpt > Filter: applies a deformation (here Smooth) to the whole object at once, still respecting the mask. One pass per click. | Deform > Smooth on everything (with Freeze). |
| **Curve (Bezier)** | An object made of a few control points joined by a smooth mathematical line, not a mesh. With **Auto handles** the line passes through every point and stays smooth; moving a point reshapes it. Our arch curve drives the splint. | None (closest: drawing a path on a surface). |
| **Ray cast / BVH tree** | Shooting a straight line from a point and finding the first face it hits. A BVH tree is a search index built once over a mesh so millions of rays stay fast; it only reads the mesh. Our splint imprint casts one ray per blank vertex along the insertion axis. | None visible (used inside Meshmixer's projection tools). |
| **Shrinkwrap modifier (Project)** | Moves each vertex of an object along an axis until it lands on a target surface, with an offset. The splint imprint does the same in code, because top and bottom must not cross and the clearance must be measured normal to the tooth. | Closest: Attract brush / Snap to surface. |
| **Dilation (rolled ball)** | Pushing a surface outwards by rolling a ball of the clearance radius over it: the gap is the same on flat cusps and vertical walls. Our splint clearance. | Offset / Make Solid offset (Meshmixer offsets a whole mesh the same way). |
| **Solidifier (OMFS) vs Solidify modifier** | Our "Solidifier en un objet" copies the parametric splint into a plain, independent mesh object (the settings stop driving it). Not Blender's Solidify modifier, which gives a surface a thickness. | Closest: Edit > Make Solid on a finished part, then working on the copy. |
| **Weld (merge vertices)** | Fuses vertices into one; faces that collapse disappear. Used to close the rim of the contact holes. | Edit > Remesh / Weld in Inspector (approximate). |
| **Text object (Font)** | A curve object whose shape is the letters of a string; Blender can turn it into a flat mesh of filled letters. Our labels are made from it, then laid on the part. | None (Meshmixer has no text tool; people import an STL of the text). |
| **STL export (apply modifiers)** | Writes the object as the modifiers show it (text cut in), in raw coordinates: 1 Blender unit = 1 mm in the file. | Export > STL. |
| **Scale (S) vs exact size** | S scales an object by a factor: its mesh is untouched but a typed 1.05 is a ratio, not mm. Our workshop cylinders instead rebuild their mesh from a diameter and a length in mm. | Transform scale handles vs typing the size in Inspector. |
| **Pivot on the 3D cursor / Cursor orientation** | A rotation can turn about the 3D cursor's point (Pivot Point: 3D Cursor) and use the cursor's own axes (Transform Orientation: Cursor). Our "Tourner autour de l'axe du curseur" sets both for one rotation. | Drop Pivot, then rotate with the widget. |
| **Bezier curve (cubic)** | A smooth curve set by its two ends and two handles: it leaves the first end along its handle and arrives at the other along the second. Our pin arms leave the cap along the surface normal and arrive along the pin's axis. | None (closest: Meshmix > tube between two points). |
| **Empty** | An object with no mesh, just a position and axes (drawn as an arrow here). Our "Pin n" Empties mark each connection's stop and axis. | Pivot. |
| **Undercut block-out** | Projecting along one insertion axis keeps only the part of the tooth seen from that direction: the splint never goes under the bulge of a crown, so it seats and comes off. | Analysis > Overhangs / Make Solid by direction (approximate). |
| **Zones by sharp angle** *(OMFS Planner)* | Face sets split wherever two neighbouring faces fold more than an angle: on a guide or cap the intrados becomes one zone, to mask in one click. No vertex moves. | Select > Crease Angle (none for facegroups). |
| **Mask from selection** *(OMFS Planner)* | The vertices selected in Edit Mode become the sculpt mask, exactly. | Select, then Freeze. |
| **Sculpt brushes (Smooth, Flatten, Clay Strips, Grab)** | Move vertices under the brush: soften, flatten, add material, pull. Masked vertices never move. | Robust Smooth, Flatten, Draw / Inflate, Drag. |
| **Collection** | A folder of objects in the outliner; an object can be in several. Hiding a collection (eye) hides its objects without deleting them. "Outils utilisés" gathers the helper objects whose modifiers were applied. | Object Browser groups (none automatic). |
| **Scene ray cast** | A ray from the mouse into the whole scene, returning the first surface met; the screw tool keeps going past anything that is not bone (guide, teeth) until it meets the bone. | Snap to surface (none for "skip these objects"). |
| **Text label** *(OMFS Planner)* | Letters laid on any printable part between two clicks, as a closed "cutter" mesh used by a Boolean modifier (Difference = engraved, Union = embossed). The part's mesh is untouched until the modifiers are applied at export. | Edit > Engrave / Emboss text (Meshmixer has no text tool; the closest is importing a text mesh then Boolean). |
| **Model base** *(OMFS Planner)* | Closes an open arch scan into a printable model: wall down the occlusal axis, flat base, bar across a horseshoe. Removes faces of the scan's ragged border, never moves a vertex, never trims the teeth zone. | Edit > Plane Cut + Extrude Boundary to plane (Make Solid). |
| **Bite check** *(OMFS Planner)* | The bite scan's shape (a strip of upper and lower teeth captured together) is fitted on both arches, then each part on its own arch: in the right occlusion both poses agree. Nothing moves: the poses are only computed; a wireframe ghost shows the fitted bite. | Align (surface to surface) of the bite on each arch, then compare. |
| **Trimmed ICP** | ICP where only the closest share of point pairs pulls: the part of a partial scan that belongs to this surface drives the fit, the rest is ignored. | None (Align uses all points). |
| **Convex hull** | The smallest convex outline around points (an elastic band around them). Its longest edge across a horseshoe spans the opening: the bar goes there. | None. |
| **Bow-tie vertex** | A vertex where two separate runs of an open border touch. Walking the border there must turn around the vertex through the faces to stay on the right run. | Inspector flags it as non-manifold. |
| **Mask Extract** | Sculpt > Mask > Extract: new object from the masked area, projected on the surface, with a Solidify modifier. | Edit > Extract. |
| **Modifier stack** | The list of modifiers on an object, applied top to bottom (e.g. Displace for the clearance, then Solidify for the thickness). Non-destructive until applied. Shown in OMFS > Confection de guide > 3. | None (Meshmixer operations are immediate). |
| **Solidify / Displace / Remesh modifiers** | Solidify: gives a surface a thickness. Displace: pushes it along its normals (clearance). Remesh (voxel): rebuilds a closed, even mesh. | Extract/Offset, Offset, Make Solid. |
| **Even Thickness (Solidify)** | Keeps the thickness constant around folds by dividing by the angle; at a sharp fold of an open border it shoots spikes tens of mm long. Off for our guides (the thickness only thins at those folds), with High Quality Normals on. | None (Extract's thickness has no such option). |
| **Show in Edit Mode (modifier)** | Whether a modifier's result is drawn while editing. Off for the guide's Dégagement / Épaisseur: Edit Mode then shows the footprint on the bone (the vertices you edit), not the 3 mm shell built on it, which would hide them. Tab back to Object Mode to see the shell. | None (Meshmixer has no live modifiers). |
| **Alt+click (cycle selection)** | Clicking again with Alt picks the next object under the mouse (behind the first one). The Outliner click always picks the right object. | Clicking in the Object Browser. |
| **3D cursor** | The red-white circle: where new objects appear, oriented by the surface when placed with the Cursor tool (or Shift + right-click). | Drop Pivot. |
| **Snapping** | Shift+Tab: moved objects stick to the surface under the mouse and can align to its normal. | Transform > Snap / Align. |
| **Transform orientation** | Which axes X / Y / Z mean during a transform: Global (scene), Local (the object's own axes)... Can be set separately for move, rotate and scale. OMFS sets **Local** for all three, so G / R / S then X uses the object's own X (e.g. a tilted cylinder's axis); pressing X twice switches to global. | Transform tool: world vs local frame toggle. |
| **Painting copy** *(OMFS Planner)* | Zones are painted "on the bone": a copy of the bone (or teeth) takes its place while painting, made automatically, and the bone comes back after the extraction. Face sets and the mask are stored on the mesh and a Sculpt stroke can move vertices (Shift = smooth), so the CBCT mesh itself is never painted. | Duplicate (Meshmixer paints on the mesh itself). |
| **Linked Flat Faces** | Select > Select Linked > Linked Flat Faces: grows a selection across neighbouring faces while the angle between them stays under a threshold (adjust in Adjust Last Operation, F9). Isolates the intrados: it stops at the rim. | None (Select > Expand has no angle limit). |
| **Subdivide (flat)** / Densifier la sélection *(OMFS Planner)* | Edge > Subdivide with Smoothness 0: cuts every selected edge at its midpoint and splits the faces (each triangle into 4 per cut). Existing vertices never move and new ones lie on the old faces, so the surface is unchanged; the seam faces around the selection are re-triangulated. Unlike the Remesh modifier, which rebuilds the whole mesh and moves every vertex. | Edit > Remesh comes closest, but it moves vertices: no exact equivalent. |
| **Object transform vs mesh data** | An object has two layers: its transform (where it is in space) and its mesh data (the vertices = the shape). Occlusion seating only ever changes the transform. | None: Meshmixer's Transform rewrites the vertices. |
| **Apply Transform (Ctrl+A)** | Writes the object's transform into its vertices, then resets the transform. The shape stays the same but the mesh data changes: the occlusion shape check flags it. Never use it on anatomy. | What Meshmixer does every time you accept a Transform. |
| **matrix_parent_inverse** | The correction Blender stores when parenting so the child doesn't jump. A block stores its pre-op matrix there, so each member's own transform stays its pre-op pose. | None. |
| **Mobile block** *(OMFS Planner)* | Empty (axes) at the centre of an arch, carrying the arch scan and what moves with it as children. Move it with G / R; local axes = reference frame axes. Scale is locked. | None (closest: Combine, which merges the meshes). |
| **Linked Duplicate (Alt+D)** | A new object that shares the same mesh data: no copy of the vertices, edits show on both. Used for the pre-op ghost. | None (Duplicate always copies). |
| **Shape fingerprint** *(OMFS Planner)* | A hash of all the vertices and faces, taken when an object joins a block and checked whenever its geometry changes: ✔ = shape untouched. | None. |
| **Spring (occlusion)** *(OMFS Planner)* | A pair of clicked points, upper then lower arch. Seating pulls the lower block so the springs shorten, while the teeth stop at the overlap limit of their zone. | None in Meshmixer; IPS CaseDesigner's virtual occlusion springs. |
| **Overlap limit** *(OMFS Planner)* | Deepest overlap allowed between the arches, one value canine to canine and one on the premolars and molars. The solver holds every point at its limit; the mesh data is untouched, only the block's transform changes. | None. |
| **Resume from here** *(OMFS Planner)* | Reseats the lower arch from its current position, sliding blocked: the solver only searches motions that close the bite (up and down, tilts), never across or front to back. Only the block's transform changes. | None. |
| **Canine spring** *(OMFS Planner)* | One of two weighted springs (right, left): upper canine tip to the lower canine / premolar embrasure. Pulls harder than the others (canine weight), so the Class I canine relation wins. | None. |
| **Midline spring** *(OMFS Planner)* | Named spring from the upper to the lower dental midline, with the weight of an ordinary spring. | None. |
| **Magnet (occlusion)** *(OMFS Planner)* | During seating, pulls the gaps between the arches closed (within range) so stable contacts form, sharing the guidance with the springs (70 / 30 by default). | None. |
| **Signed distance** | Distance from a point to a surface, negative when the point is behind the face normal (inside). Overlap between arches = negative distance. | Inspector / Deviation colour map (unsigned). |
| **Open border** | Edges used by one face only: the cut edge of a scan. Inside/outside means nothing there, so contact tests skip those faces. | Inspector's "holes" (blue). |
| **Draw handler** | Python code that draws extra lines in the 3D view each redraw (here the zig-zag springs), without creating objects. | None. |
| **Modal timer** | An operator that runs a little at every timer tick, so the viewport redraws between steps: used to animate seating. Esc cancels. | None. |
| **Adjust Last Operation (F9)** | The panel at the bottom left after an operation: change its settings and see the result live. | The tool's settings panel before Accept. |
| **Hide / Reveal (H / Alt+H)** | Hides selected faces in Edit Mode; Sculpt Mode leaves them untouched. Display and protection only. | Freeze / Unfreeze. |
| **Solidify shell vertex group** | Solidify can write the vertices of one side into a vertex group. With the thickness grown outwards, that side is the original surface (intrados); our "Lisser l'extérieur seulement" smooths everything except that group (inverted Smooth). | None. |
| **Cut edge** *(OMFS Planner)* | Confection de guide > 5: a Boolean Difference with a hidden box filling one side of the osteotomy plane, so the guide's edge lies exactly on the cut and guides the saw. Re-click after changing the cut. | Edit > Plane Cut. |
| **3D Viewport** | The editor showing the 3D scene. | The main Meshmixer view. |
| **Editor / Area** | Blender's window is split into areas, and each area shows one editor (3D Viewport, Outliner, ...). | None (Meshmixer has a single fixed layout). |
| **Region** | A part of an area: header, toolbar (T), sidebar (N), main view. | None. |
| **Header** | The strip of menus at the top of each area. | The top menu bar. |
| **Top bar** | The very top of the window: File/Edit menus, workspace tabs. | The top menu bar. |
| **Sidebar (N panel)** | Right-hand side of the viewport, organised in **tabs**. Ours is the **OMFS** tab. Toggle with **N**. | The tool panel that opens on the left when you pick a tool. |
| **Panel** | A collapsible box of buttons inside a region. | A tool's property panel. |
| **Toolbar (T)** | Left-hand side of the viewport: interactive tools (select, move, measure...). Hidden in the OMFS layout. | The left vertical menu (Select, Sculpt, Edit, Analysis...). |
| **Outliner** | Tree list of everything in the scene. In the OMFS layout it is a flat list of objects. The arrow icon shows whether an object is selectable (greyed = locked). | Object Browser. |
| **Properties editor** | Tabs of settings for render, scene, object, modifiers, materials... Hidden in the OMFS layout. | None (spread across Meshmixer's menus). |
| **Workspace** | A saved arrangement of editors for one task (Layout, Sculpting...). We add **Planning**. | None. |
| **Viewport shading** | How the viewport draws surfaces: Wireframe, **Solid** (ours), Material, Rendered. Display only, never changes the mesh. | View > Shaders / Toggle Wireframe. |
| **Studio light** | Solid-mode lighting that is fixed relative to the camera, so anatomy is always lit from the front. | The default Meshmixer lighting. |
| **Cavity** | Solid-mode effect that darkens grooves and brightens ridges. Makes bone surface detail readable. | None. |
| **Object colour** | A per-object colour used when shading colour is set to "Object". We colour by role. | Roughly: per-object colour in the Object Browser. |
| **X-ray** | See-through display (Alt+Z). Useful to look at teeth inside a scan. | Transparent shader. |
| **Backface culling** | Hides the back side of faces. Off for us, so cut or open meshes can be seen from inside. | None (Meshmixer tints back faces). |
| **Clip start / end** | Nearest and farthest distance the viewport draws. Set to 0.1 mm to 10 m so anatomy isn't sliced near the camera. | None. |
| **Frame All (Home)** | Zooms the view so all objects are visible. | View > Recenter View. |
| **Centre view (C)** *(OMFS shortcut)* | Blender's `view3d.view_center_pick` (normally Alt + middle-click) mapped to **C**: the point under the mouse becomes the centre of orbit and zoom. Replaces Blender's circle select on C. | C (centre on point under cursor). |
| **Trackpad navigation** | Two-finger swipe = orbit, Shift + two fingers = pan, pinch = zoom. The navigation gizmo (top right) can be dragged or clicked too. | Alt + left/middle/right drag. |
| **Auto Depth / Zoom to Mouse Position** | Preferences > Navigation: orbit and zoom around the surface under the mouse instead of the view centre. **Off** in OMFS, so orbit and zoom turn around the point set with C. Display only. | None (Meshmixer turns around the C point). |
| **Emulate Numpad** | Preferences > Input: the number row acts as the numpad (1 front, 3 right, 7 top, Ctrl = opposite side). | None. |
| **Keymap** | The table of shortcuts per editor (Preferences > Keymap). Extensions add their own entries, e.g. our C. | Hotkeys list. |
| **Active tool / WorkSpaceTool** | The tool chosen in the toolbar decides what a left click or drag does, and its shortcuts win over the editor's. Our **Navigate** tool makes drag = orbit, Shift + drag = pan, click = select. Activated on Import Case. | Choosing a tool in the left menu. |
| **Object mode / Edit mode** | Object mode moves whole objects; Edit mode edits vertices/faces. OMFS works in Object mode. | Object level vs the Select tool. |
| **Operator** | One Blender command (e.g. `omfs.import_case`), undoable, callable from a button, menu, search (F3) or Python. | A Meshmixer command/tool (e.g. Edit > Make Solid). |
| **Undo (Ctrl+Z)** | Operators marked UNDO can be undone. | Ctrl+Z. |
| **Custom property / PropertyGroup** | Extra data we attach to objects and save in the .blend, e.g. `object.omfs.role`. | None. |
| **Role** *(OMFS Planner)* | Our label on each object: Bone, Teeth, Scan, Nerve, Skin, Segment, Guide, Other. Sets colour and default lock (everything from the CT/CBCT is locked). | None. |
| **Extension** | Modern Blender add-on package, described by `blender_manifest.toml`. Ours adds the OMFS tab and operators. | None (Meshmixer has no plug-ins). |
| **Add-on** | Python code that extends Blender; extensions are the current packaging of add-ons. | None. |
| **Application Template** | A startup configuration that replaces Blender's default UI and scene. Ours is the clean OMFS Planner interface. | None. |
| **Preferences** | User-level settings (enabled extensions, keymap, themes). Saved separately from .blend files. | Meshmixer Preferences. |
| **bpy** | Blender's Python API: everything in this project is written with it. | None. |
| **Clipping region (Alt + B)** | Hides everything outside a box in one 3D viewport. The GPU discards the hidden part at draw time: the mesh data is untouched, and it is instant on large meshes. Our **Slab Only** sets it to two parallel planes of any orientation (the slab). Alt + B again removes it. | Hide / Show tools have no clipping; the closest is a Plane Cut preview without accepting it. |
| **Section plane / slab** *(OMFS Planner)* | A plane moved along its normal in mm, and a slab of chosen thickness centred on it. Drawn by a draw handler, not an object. | Plane Cut's plane, without cutting. |
| **Orthographic view** | A view without perspective: parallel lines stay parallel and sizes do not shrink with depth, so distances on screen are true to scale, like a radiograph. Toggle with numpad 5 (or 5 with Emulate Numpad). | View > Orthographic. |
| **Section contour / cap** *(OMFS Planner)* | Contour: the line where a mesh crosses the section plane, computed from its triangles and drawn by a draw handler. Cap: the inside of that contour filled, so a cut object looks solid. Nothing is added to the mesh. | Plane Cut's preview outline; Plane Cut with "fill" (but that one changes the mesh). |
| **Even-odd rule** | A point is inside a shape if a line from it crosses the outline an odd number of times. Fills holes correctly (a canal inside bone) even when a segmentation crosses itself. | None (internal). |
| **Depth test** | When drawing, the GPU keeps a pixel only if nothing nearer was drawn there. Our contours skip it (always on top); caps use it (hidden by what is in front of them). | None. |
| **Boolean modifier** | Combines an object with another one: Union, Difference or **Intersect** (only the common volume). As a modifier it changes what this object shows, never its mesh data, until applied. Solvers: **Manifold** (fast, needs closed meshes), **Exact** (copes with small defects, much slower), Float. | Edit > Boolean (Union / Difference / Intersection), which changes the mesh at once. |
| **Copy Transforms constraint** | Makes an object take another object's position, rotation and scale, live. Our intersection overlay follows A this way, without parenting it to A. | None. |
| **Closed (watertight) mesh** | Every edge is shared by exactly two faces: the mesh has an inside and a volume. A scan is open; a CT segmentation can have a few open edges. | Analysis > Inspector (shows holes and non-manifold areas). |
| **Snapshot** *(OMFS Planner)* | A result computed once and stored in its own mesh, instead of a live modifier: used when the live computation would be too slow to follow a drag. | Every Meshmixer operation (results are always baked). |
| **Geometry Nodes modifier** | A modifier whose effect is a node graph. Ours (OMFS Distance Map) reads the source and the target and writes per-vertex attributes on the *evaluated* mesh only: the mesh data on disk is never changed, removing the modifier removes the map. | None (Meshmixer has no procedural modifiers). |
| **Evaluated mesh** | What Blender shows and exports after the modifiers have run, rebuilt whenever an input changes. The original mesh data stays as imported. | None. |
| **Named attribute** | Extra data per vertex (or face...) stored under a name, e.g. "OMFS distance". A colour attribute can be shown in Solid mode with Color = Attribute. | Vertex colours. |
| **Geometry Proximity node** | For every point, the nearest point on another geometry's surface and the distance to it. | Analysis > Deviation (colour map of distances between two meshes). |
| **Offscreen render (GPUOffScreen)** | Draws a 3D view again into an invisible image instead of the screen: same scene, same shading and clipping, but none of the interface. Our snapshots use it, then draw the contours and caption on top. | File > Export screenshot (but that one captures the interface). |
| **Scale bar (orthographic)** | In an orthographic view one millimetre has the same length everywhere on screen, so a bar of known length is a true scale. In perspective, nearer things look bigger: no single scale. | None. |
| **Brush keys (Sculpt Mode)** | Ctrl held while dragging inverts the brush (+ ↔ −: Clay Strips removes, Flatten accentuates, Mask erases); F then mouse = radius, Shift+F = strength (radial control, click to confirm); Shift held = smooth with any brush. They change the brush, not the mesh. | Ctrl (invert), brush size / strength sliders. |
| **Mega Boolean** *(OMFS Planner)* | Applies every Boolean modifier of the guide in a fixed order (unions, differences, cut edge, fixation holes), then the cap's; a sleeve cylinder crossing a pin of the cap is subtracted from the cap too, and the guide is hollowed where a male of the cap sits in its own volume. Holes already applied are remembered on the part (custom property) and dug again after a later union that reaches them. Applying writes the result into the mesh data. | Edit > Boolean, one after the other in the right order. |
| **Plane cut** *(OMFS Planner)* | Drag a line on the screen: a plane through it (edge-on to the view) drives a Boolean Difference with a half-space box parented to it, so the part stays closed and the cut is live until applied. The plane is moved with the Transform gizmo (arrows + rings). | Edit > Plane Cut. |
| **Erase & Fill** *(OMFS Planner)* | Deletes the selected faces, fills each hole with a face (edge loop fill), refines it to the rim's edge length and relaxes the new vertices (Laplacian smoothing) while the rim stays fixed. Mesh data changes only inside the hole. | Select > Edit > Erase & Fill (F). |
| **Custom data layer (bmesh)** | Extra per-vertex / edge / face value stored in the mesh (bmesh `layers.int`). Used to remember which elements are old while bmesh operators run: they clear the `tag` flags. | None. |
| **Pins follow the guide** *(OMFS Planner)* | Each pin is an Empty; when the guide follows the segment its Empties move with it (like a child of the guide) and every pin part is rebuilt from them, so the arms reach the pins where they are now. Blender's Parent would move the parts rigidly but not rebuild the arms. | None. |
| **Connected components (loose parts)** | Groups of faces that touch through shared edges. The upper arch is split into segments by breaking the links between faces on either side of each osteotomy line, then reading which faces still hang together. New meshes get copies of each group's faces; the scan's mesh data is unchanged. Blender's own tool: Edit Mode > Separate > By Loose Parts. | Edit > Separate Shells. |
| **Boolean with a Collection operand** | One Boolean modifier that uses every object of a collection as the cutter, as if they were one: the splint's wire holes are all subtracted in a single operation, and a hole added to the collection is cut too. Live and non-destructive until applied. | Boolean Difference after combining all the cutters into one object (Edit > Combine). |
| **Restricted solver motions** *(OMFS Planner)* | The seating solver searches only some of the six rigid motions (a basis of allowed rotations and translations): an upper segment only translates, its angles stay the surgeon's, except the axes unlocked with « Affiner ». Like transform locks, but for the solver instead of the hand. | None (closest: moving with Transform along one axis only). |
| **Euler angles** | Three successive rotations about three axes (here torque, then tip / cant, then rotation about the vertical, on the segment's own clinical axes). Blender shows object rotations this way too. Only the object's transform changes, never the mesh. | Transform > rotation fields. |
| **Envelope (smoothed)** *(OMFS Planner)* | A line kept outside every measured point, then smoothed: a running maximum over a stretch, then an average. The splint's buccal and lingual outline never cut into the clearance, yet stay round. Computed on the outline only; the scans are never changed. | None (closest: drawing the outline by hand, then Smooth). |
| **Signed distance field (distance grid)** | A 3D grid that stores, at each node, the distance to a surface (negative inside), plus the normal and closest point there. Built once per arch; then the distance of thousands of points is read in one go by interpolation instead of being searched point by point. Blender uses the same idea inside Mesh to Volume / Volume to Mesh. The arch meshes are never changed. | None. |
| **Line search** *(OMFS Planner)* | The seating's full step is tried whole, then halved while it does not improve the balance of springs, magnet and overlap. So the solver can't swing back and forth between two contacts, and it stops at the equilibrium. | None. |
| **Scene** (second scene) | A Blender file can hold several scenes, each with its own objects. The print plate is a separate scene ("Impression") holding copies of the parts: turning a part there changes nothing in the plan. | None: Meshmixer has a single workspace. |
| **Evaluated mesh** | The object as displayed, every modifier and Boolean applied, without changing the stored mesh. The print scene copies this, so what is printed is what is seen. | The mesh after "Accept" on every tool. |
| **Build volume / build plate** | The box the printer can reach (Mars 4 Ultra: 153.36 x 77.76 x 165 mm) and the plate the print hangs from. Drawn as a wire box and a slab; nothing printable outside. | Print bed in the Print view. |
| **SLA support, raft** | Thin pillars that hold the part while it is printed upside down, with tips that touch it. The raft is a rigid plate cured against the build plate under all the parts; its bevelled edge lets a scraper under. | Analysis > Overhangs (supports); no raft. |
| **Support blocker** *(PrusaSlicer)* | A volume inside which no support may start or end. A thin slab over each bearing surface (the face that fits the bone or the teeth) keeps support marks off it. | None (closest: removing supports by hand). |
| **Island** | A region of a layer with nothing printed under it: it would cure in mid-air. UVtools lists them; the export refuses a file with one over 1 mm2. | None. |
| **.sl1 / .goo** | Sliced print files: one image per layer plus the exposure settings. .sl1 is PrusaSlicer's (a zip of PNG); .goo is Elegoo's, the one the printer reads. | None (Meshmixer exports meshes only). |
